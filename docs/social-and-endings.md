# 交涉、队友与结局

> 本文整理战斗交涉、队友规则和结局条件。概率权重、边界情况与剧情细节仍待设计。

## 战斗台词与招募

敌方台词可随战斗进程或残血状态触发，并暗示其阵营偏好。

战斗中可消耗 AP 尝试邀请敌人加入队伍。成功率由基础概率、阵营差距及敌人剩余 HP 比例共同决定：

```text
SuccessProbability = BaseRate
  + w1 × (1 - AlignmentDiff)
  + w2 × (1 - CurrentHP / MaxHP)
```

若双方阵营差异超过敌人的“交友圈容忍阈值”，招募直接失败并激怒对方。`AlignmentDiff` 的距离公式、权重、概率上下限、容忍阈值与失败后果尚未确定。

## 队友规则

* **怪物队友**：可消耗样本强化；其阵营坐标天生固定，不能通过注射改变。
* **人类队友**：各自拥有固定阵营坐标，不能被注射改变。人类队友只接受与自身坐标相近的样本；部分极端纯人类队友拒绝所有注射。强行违背边界可能导致排异、叛变或反目。

队伍人数上限、编队与替补、队友行动控制，以及样本强化/排异的具体效果尚待决定。

## 结局判定

击败最终 Boss 时，根据主角侵蚀度和阵营坐标判定结局。坐标正向为 Law/Justice，负向为 Chaos/Evil。

| 结局 | 当前条件 |
| --- | --- |
| 天使类 | 侵蚀度为 100%，`law_chaos > 50` 且 `justice_evil > 50` |
| 堕天使类 | 侵蚀度为 100%，`law_chaos > 50` 且 `justice_evil < -50` |
| 异神类 | 侵蚀度为 100%，`law_chaos < -50` 且 `justice_evil > 50` |
| 恶魔类 | 侵蚀度为 100%，`law_chaos < -50` 且 `justice_evil < -50` |
| 未完全进化 | `0% < 侵蚀度 < 100%`（有注射记录但未达完全异变阈值） |
| 纯人类 | 侵蚀度为 0%（全程零注射） |

## 待决定

* 若侵蚀度达到 100% 但坐标不满足四种异变条件，采用什么结局。
* 阈值 `50/-50` 是否包含等于边界的情况；显示舍入值与实际判定值如何区分。
* 若同一角色满足多个结局条件，判定优先级是什么。
* “全程零注射”是否必须通过注射历史单独判定。
* 结局是否只看主角，队友状态、重要剧情选择或 Boss 处理方式是否参与。
* 招募失败后果、重复交涉限制、队伍上限及队友加入后的控制规则。
