# 角色属性与战斗规则

> 本文集中记录角色/敌人属性、装备与战斗数值。已明确的概念与尚待平衡的公式分开标示；公式中的系数和行动细节仍需验证。

## 角色属性框架

角色与敌人共用同一套属性框架；具体角色可因种族、能力或规则限制而不具备某些属性。角色没有通用等级，数值变化来自装备、武器熟练度、Buff/Debuff、异变和剧情效果。

### 本体属性与资源

* **HP**：当前生命值与生命值上限。主角纯人类状态下 HP 很低，目标是仅能承受约 1–2 次攻击；不通过角色等级提升。
* **MP**：当前魔力与魔力上限。纯人类 MP 上限为 0，不能施放魔法。
* **基础物攻**：角色徒手攻击的能力。未使用武器时物理攻击只使用基础物攻；使用武器时，基础物攻与所选武器攻击力共同参与计算。
* **基础魔攻**：角色自身的施法能力，与法术威力共同参与魔法伤害计算。
* **防御力**：用于伤害计算的防御数值，和护甲 Shield 分开记录。
* **速度**：决定战斗中的行动顺序。
* **AP**：回合制行动资源。记录每回合可用 AP 与当前剩余 AP；行动消耗 AP。AP 和速度作用不同。

### 武器与装备

* 角色有左手、右手装备槽，并可拥有武器库存。
* 攻击时必须选择实际使用的武器；角色持有多把武器时，其余武器不参与该次攻击结算。
* 另有头盔、防具、鞋子装备槽。饰品槽尚未确定。
* 武器具有武器攻击力；防具可提供 Shield。装备也可在后续设计中修正其他属性或提供特殊效果。

### 武器熟练度

武器熟练度按单一武器或武器类别记录，通过使用相应武器战斗而提升。它不是角色等级，可提高相应武器伤害并降低其 AP 消耗。具体成长幅度、上限和减耗规则待平衡设计确定；基础物攻不因通用等级提升。

### 抗性与效果

* **魔法属性耐性**：每种魔法属性分别记录伤害倍率，范围 `0.0–2.0`。`1.0` 为正常伤害，低于 `1.0` 为抗性，高于 `1.0` 为弱点，`0.0` 为免疫。
* **异常状态抗性**：和魔法属性耐性分开，用于抵抗中毒、眩晕、沉默等状态效果。具体状态规则待定义。
* **Buff/Debuff**：以效果列表记录，效果应有持续时间、来源和叠加规则；可修正属性、造成持续伤害或限制行动。注射产生的即时恢复和增益也由效果系统表达。

## 伤害与护甲

### 物理伤害

当前设计公式：

```text
PhysicalDamage = max(1,
  (BasePhysicalAttack + WeaponAttack)
  × (1 + WeaponProficiencyBonus)
  - TargetDefense
)
```

徒手攻击时 `WeaponAttack = 0`，且不应用武器熟练度加成。熟练度加成按武器或武器类别配置，不代表角色等级。最小伤害、熟练度收益与最终结算顺序仍需通过战斗样例验证。

### 魔法伤害

当前设计公式：

```text
MagicDamage = max(0,
  (BaseMagicAttack + SpellBasePower)
  × (1 + (abs(LawChaos) + abs(JusticeEvil)) / 100)
  - TargetDefense
) × TargetElementResistance
```

`TargetElementResistance` 是目标对应魔法属性的伤害倍率。阵营加成使用坐标绝对值，代表偏离中立的程度；这项设计是否符合预期、以及公式的数值范围仍待验证。魔法伤害下限为 0。最终伤害再由 Shield 吸收。

### Shield 护甲缓冲

Shield 是装备提供的独立承伤缓冲，不等同于防御力。伤害先按攻击公式计算，再由 Shield 吸收；Shield 不足时，溢出部分扣除本体 HP。

```text
若 Shield >= Damage：本体不受伤，Shield 减少 Damage
若 Shield < Damage：Shield 降至 0，本体承受 Damage - Shield
```

装备定义 Shield 上限，当前 Shield 值单独记录。Shield 是否战后自动恢复、如何修理，以及多段伤害和破甲效果如何处理，尚待决定。

## 仍待确定

* 每回合 AP、各行动成本、回合结构与速度排序规则。
* 是否采用命中/闪避判定、随机伤害、暴击、穿透及其结算顺序。
* Shield 的恢复/修理规则、不同防具的缓冲量和破裂反馈。
* 武器熟练度成长、上限、伤害加成与 AP 减耗上限。
* 魔法伤害是否使用与物理相同的防御力；当前公式暂用统一的 `TargetDefense`。
* 魔法伤害阵营倍率的具体设计意图和范围。
* 饰品槽及装备携带限制。
