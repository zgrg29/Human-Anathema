# 《项目代号：非人与尘世》（Human & Anathema）完整游戏企划书

---

## 一、 核心概念与愿景 (Core Concept & Vision)

* **游戏类型**：无跑图、菜单驱动型、回合制战术 RPG（强策略、资源管理与博弈）。
* **核心基调**：克苏鲁式的身体异变与抉择痛苦，凡人以弱胜强的悲壮史诗。
* **开发与验证架构**：采用“纯文本 Headless API 核心 + 自动化平衡性测试（强化学习 RL 兼容）”的设计，彻底解耦底层逻辑与未来表现层。
* **通关自由度**：支持**“零注射纯人类通关”**与**“多维非人化异变（4种异变结局 + 2种特殊结局）”**。

---

## 二、 核心架构与游戏循环 (Core Loop)

彻底抛弃开放世界与跑图迷宫，游戏精简为两大核心阶段的循环：

1. **战斗阶段 (Combat Phase)**：硬核回合制战术对抗，考验护甲缓冲、武器熟练度、战术道具、台词交涉与生死关头的注射抉择。
2. **整备阶段 (Rest Phase)**：无跑图菜单化设施交互，包含：
   * **医疗所 / 休息区**：恢复整备、NPC 动态对话。
   * **黑市 / 炼金工坊**：买卖武器、防具、战术道具及注射样本。
   * **情报屋 / 议事厅**：与基于阵营坐标态度动态变化的 NPC 交互。
   * **武器库 / 训练场**：管理武器熟练度与队伍配置。

## 三、 核心系统与数值机制 (Mechanics & Formulas)

### 1. 二维正交坐标系（四象限阵营轴）
玩家的抉择与注射行为实时影响两个独立的极性轴（范围：$-100$ 至 $100$）：
* **Order（秩序） $\longleftrightarrow$ Chaos（混沌）**
* **Justice（正义） $\longleftrightarrow$ Evil（邪恶）**

### 2. 主角与成长系统
* **纯人类状态（开局默认）**：
  * **HP**：极低（仅能承受 1-2 次攻击），无法通过常规升级提升。
  * **MP & 魔法**：默认为 $0$，纯人类**绝对无法**释放魔法。
  * **物理成长**：通过战斗中使用特定武器提升**武器熟练度**（$\text{Level} \times 0.05$ 伤害加成，减少 AP 消耗），并微幅增加肌肉量以装备重型兵器。
* **非人/注射者状态**：
  * 通过击败敌人获取**注射样本**（原体液系统），可在战外或**战斗回合中即时注射**。
  * **双刃剑效果**：瞬间恢复、提供强力 Buff，但会改动阵营坐标并累积**侵蚀度 (Corruption)**。

### 3. 攻防体系与护甲缓冲
* **护甲缓冲法则（Human Shield）**：敌人的伤害必须先扣除外部装备/防具提供的 **Shield（护甲值）**。
* **结算规则**：$\text{Shield} \ge \text{Damage}$ 时本体无损；$\text{Shield} < \text{Damage}$ 时护甲破裂，溢出伤害直接重创极低 HP 的本体。

### 4. 伤害计算公式
* **物理伤害公式（人类武器流派）**：
  $$\text{PhysicalDamage} = \max(1, \, (\text{WeaponBasePower} \times (1 + \text{ProficiencyLevel} \times 0.05)) - \text{EnemyDefense})$$
* **魔法伤害公式（非人异变流派）**：
  $$\text{MagicDamage} = \text{SpellBasePower} \times \left(1 + \frac{|\text{OrderScore}| + |\text{JusticeScore}|}{100}\right) - \text{EnemyMagicResist}$$

## 四、 战斗交互、招募与注射习得系统

### 1. 战斗台词与动态招募
* **敌方台词**：随战斗进程或残血触发，暗示其阵营偏好。
* **招募公式**：在战斗中消耗 AP 尝试邀请敌人加入队伍。成功率受**阵营差距绝对值 ($\text{AlignmentDiff}$)** 与 **敌人残血度 ($\frac{\text{CurrentHP}}{\text{MaxHP}}$)** 共同决定：
  $$\text{SuccessProbability} = \text{BaseRate} + w_1 \times (1 - \text{AlignmentDiff}) + w_2 \times \left(1 - \frac{\text{CurrentHP}}{\text{MaxHP}}\right)$$
  *(超过敌人的“交友圈容忍阈值”则直接失败并激怒对方)*

### 2. 队友生态与限制
* **怪物队友**：可通过消耗样本强化，但**天生阵营坐标固化，无法通过注射改变**。
* **人类队友**：拥有独立固定的阵营坐标且**无法被改变**。人类队友**只接受与其坐标相近的样本**（部分极端纯人类队友坚决拒绝一切注射），若强行违背可能引发排异、叛变或反目。

### 3. 注射技能习得与基因掠夺
* **技能突变**：注射样本时，有概率随机习得相关技能。若使用的是**特定敌人的专属样本**，其生前掌握的技能被抽中的权重大幅提升。
* **门槛约束**：通过注射意外习得的高阶魔法，必须在角色的阵营坐标满足技能门槛时方可生效，否则处于“排异锁定”状态。纯人类角色无 MP 且无注射行为，无法触发该机制。

## 五、 结局判定树 (Ending Tree)

当击败最终 Boss 时，根据玩家当前的 $\text{corruption}$（侵蚀度）与双轴坐标判定：

1. **天使类结局**：$\text{corruption} = 100\%$ 且 $\text{Order} > 50, \text{Justice} > 50$。
2. **堕天使类结局**：$\text{corruption} = 100\%$ 且 $\text{Order} > 50, \text{Evil} < -50$。
3. **异神类结局**：$\text{corruption} = 100\%$ 且 $\text{Chaos} < -50, \text{Justice} > 50$。
4. **恶魔类结局**：$\text{corruption} = 100\%$ 且 $\text{Chaos} < -50, \text{Evil} < -50$。
5. **未完全进化结局**：$0 < \text{corruption} < 100\%$（有注射记录但未达终极阈值）。
6. **纯人类结局**：$\text{corruption} = 0\%$（全程零注射，以凡人之躯通关）。
